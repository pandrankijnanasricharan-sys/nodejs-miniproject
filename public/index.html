How it works

1

Select

The browser reads the selected file's size immediately.

2

Set target

You decide how small the output should be.

3

Compress

The server chooses a method based on the file type.

4

Download

You see the final size and download the result.

Important note

A target size is a goal, not a mathematical guarantee for every file type. Images can be adjusted by changing quality and dimensions. PDFs and already compressed formats may not be able to reach an arbitrarily small target without changing their contents.
